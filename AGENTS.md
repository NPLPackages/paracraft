## Hard rules (NPL)

1. Never Lua `require()` — use `NPL.load("(gl)script/...")`.
2. Modules: `commonlib.gettable("Namespace.Module")`.
3. OOP: `commonlib.inherit(parent, commonlib.gettable("..."))`.
4. User strings: `L"..."` / `L'...'`.
5. MCML: call `page:Refresh()` after data changes.
6. Match existing patterns and file headers; no foreign frameworks.

```lua
NPL.load("(gl)script/apps/Aries/Creator/Game/game_logic.lua");
local GameLogic = commonlib.gettable("MyCompany.Aries.Game.GameLogic");
```

Namespaces: `MyCompany.Aries.*`, `MyCompany.Aries.Game.*`, `System.*` (from main package), `Map3DSystem.*`, `commonlib.*`.
